WHAT IT IS

先说清楚它是什么

olua 是一个 完整开源 的 2D 即时战斗游戏项目 —— 不是教程里的片段，也不是只有前端的 Demo。 服务端、运营后台、地图管线、数值表、掉落表都在仓库里，改一下配置就能跑出自己的版本。

它是 学习项目，不是商业产品。所以这里除了游戏截图，更多的是： 数据怎么流、边界怎么划、改坏了怎么在合并前发现。

ARCHITECTURE

三个端，一个权威

客户端玩、服务端算、管理端改

客户端

玩家看到的全部

登录、选角、战斗、背包、商城、社交。只负责输入与表现，本地不判定任何战斗结果。

Cocos Creator 3.8.7
TypeScript · 4.65 万行

服务端

唯一手写接口的地方

账号、角色、地图、怪物、战斗结算、掉落、邮件。两个进程共用一个 SQLite，契约从这里生成。

NestJS 12 + node:sqlite
23 模块 · 4.95 万行

管理端

运营改数据的地方

地图刷怪区、NPC、碰撞盒、掉落表、装备体系、特效、权限与日志，50 个页面，改完即生效。

React 19 + Vite
50 页面 · 4.11 万行
