设计系统总纲通用组件

通用组件COMPONENTS

管理端 components/ui.tsx 里 12 个通用件 + 弹窗 / 表格 / 分页 / 筛选条 / 表单零件的全部重设计。 每个演示都是真实页面里的用法（角色管理、封禁确认、技能编辑），不是悬空样例。

01

按钮

Buttonui.tsx › Button · 4 变体

一个区域只允许一枚实心金按钮。删除类操作用「火色描边」，只有二次确认框里才用实心火色 —— 让危险动作永远多一步。

primary 金锭 / outline 次操作 / ghost 无框 / danger 描边危险 / solid-danger 仅确认框

三档尺寸 26 / 32 / 38；loading 与 disabled 必须可区分 —— 前者带转轮与进行时文案

02

行内动作

Icon Button

表格行、卡片右上角的小动作只用图标，hover 才显形，避免每行三个按钮把表格撑满。

↑ 默认态 · ↓ 悬停态（编辑点亮金、删除点亮火）
03

输入与字段

Input · Select · Fieldui.tsx › Input / Select / Field

字段默认标签在上、控件在下（Field 的既有口径）—— 标签左置会吃掉控件宽度。 只读字段用纯文本 + 虚线下沿，不做灰掉的输入框。

错误态：火色边 + 3px 火环；只读：虚线下沿 + 正常字色，看起来就是「这里不改」

04

选择类

Checkbox · Radio · Toggle · Segment · Tabs

勾选框 15px 方形；单选是同尺寸圆形内嵌金环；开关只用于偏好设置；分段用于 3–4 个互斥小集合。

新公告推送 离线邮件

复选框、单选、开关三件套；触控区 ≥ 26px

分段 = 同一尺度上的取值切换；Tabs = 不同内容区。

12

弹窗

Modal · 四档宽度Modal.tsx › sm / md / lg / xl

宽度只有四档，页面不许自己传 max-w：sm 确认与单字段、md 普通编辑、lg 长表单、xl 工作台。 Esc 关闭、点遮罩关闭、内容区独立滚动、footer 固定 —— 全部由外壳提供。
