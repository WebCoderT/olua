控件状态图谱SPEC v1

石 · 金 · 火 三个色阶贯穿全部控件：金 = 可交互与选中，火 = 危险与错误，绿 = 服务正常。 每个状态都用固定类钉住（is-hoveris-focusis-invalid…）， 不必摸鼠标即可评审。真实交互版本见登录页与概览页。

Inputs · 输入框

高度 44，左对齐单行；错误态由提交校验触发，不清空已输入内容。

Default

默认：金线 22% 透明度，占位字 #6E604A

Hover

边线提到 36%，无背景变化

Focus

金线 + 3px 光环 + 内衬高光

Filled

已填且未聚焦：边线 30%，字色最亮

Invalid

请输入管理账号

Disabled

整体压暗 42%，禁止光标；不参与 Tab 序

Buttons · 按钮
