## 17:00 称号名牌改挂头部信息栏（与名称/血条同节点、不缩放）
- 需求：称号显示节点放进角色头像信息节点里，与名字血条同一个节点，不缩放。
- 改动：`roleShowLayout.title` 去掉 position/scale，改为 `{ siblingIndex: 0, size: 260×140 }`（size 只是加载首帧前占位；帧到后 RAW 覆盖）；`RoleDisplay.updateTitleShow` 改为 `this.head.insertChild(node, roleShowLayout.title.siblingIndex)`——位置交给头部 FlexCol 的纵向布局、不再 setScale/setPosition，重建前先 removeFromParent（destroy 当帧仍挂父节点会与新建名牌同时排一次布局）。
- 引擎口径（读 3.8.7 layout.ts 确认）：VERTICAL 类型只改容器 height、**从不改 width**，`alignHorizontal` 时 `fnPositionX` 直接返回 0（子件横坐标恒为容器原点）→ 名牌变宽不会挤动名称/血条；CONTAINER 只按内容算高度，**不缩放子件**（只有 resizeMode=CHILDREN 才会改子件尺寸）；`startPos=(verticalDirection-anchorY)*baseHeight` + `sign=-1` → 下标 0 在最上。
- **顺手修真 bug（上一轮引入）**：删掉 createHead 里文字称号占位后，`updateHead` 仍按 `children[2]/[3]` 取血条/血量文字 → 实际拿到 Label/undefined，血条与血量文字**静默不刷新**。改为按名字取件（createHead 给血条/血量文字起名 `role_hp_bar` / `role_hp_text`，血量文字原名误写成 role_name）；`RoleDisplay` 的 getChildByName 登记 config-leak allowlist（与 MonsterManager 查 monster_head 同类）。
- 校验：tsc 基线（仅 Login.ts 2 处历史 unused）、两审计 PASS、11 个单测 PASS（test-title 新增 4 条：插在头部容器/不定位不缩放/按名取件/名字成对）、26s 回写复检一致。
