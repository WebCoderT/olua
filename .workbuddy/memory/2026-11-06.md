# 2026-11-06

## #670 怪物 AI 全部上服务端（多端画面一致）

用户原话：「处理 #670，现在要求怪物 AI 全部在服务端，下发至客户端，必须保持多用户画面一致」。
issue 原标题只是「怪物对着尸体放技能」，被扩成「AI 全服务端化 + 一致性」。

**#670 本体根因**：`RolesService.applyMonsterHit` 在 `previous <= 0`（玩家已倒下）或不在线时 `return null`，
而 `MonsterAiService.attack()` 只把它当「这一下落空」→ `runtime.target` 不清、`positions` 里那条 hp>0
的缓存不删 → 下一拍又把尸体选成目标。更糟的是 `castSkill()` 无论命中与否都 `pendingCasts.push(cast)`。
**修法 = 认结算结果，不是读血量**：`forgetTarget(accountId)` 删位置记录 + 清掉所有怪身上指向该账号的
`target`；`castSkill()` 改成先结算再落账（拿不到 hit → 不记冷却、不进硬直、不发 casts，返回 false）。

**多端一致的三个缺口**：① world 快照 `x/y` 是出生点，而 `monster-ai` 增量帧「有变化才发」→ 站着不动的
怪永远不会被纠正；② 血量只在 `hits` 里（只发给出手者本人）；③ 客户端 `serverAuthority=false` 时仍跑本地 AI。
修法：`withLiveMonsterPositions()` 覆盖 world 帧坐标（`worldJoin` 应答 + `broadcastWorld` 两处）；
`monster-ai` 帧带必填 `hp/maxHp`、`hurt` 也算「有变化」；客户端本地 AI 全删。

**击退搬服务端**：原计划「删掉客户端 push，不做击退」，发现 `skills.push_distance` 有数据（1001 烈火剑法 = 120px），
改成 `applyPush(instanceId, fromAccountId, distance)`：方向 = 施法者 → 怪，时长取
`runtime_params.monster_ai.pushDuration`（新字段，出厂 200），`stepMonster` 里击退优先于施法硬直。
**不需要新协议帧**，落点走普通位置广播。客户端 `stepServer` 步长加追赶
（`max(moveSpeed, distance / 0.2s)`），否则 120px 击退要拖一秒多才补齐。

**踩坑**：
- `skillOf()` 返回的是 `applySkillOverrides` 归一化后的**驼峰**对象，我第一版写 `Number(skill.push_distance)`
  拿到 `undefined` → 击退静默失效。要 `SkillSource` 补 `push_distance` 列 + 映射成 `pushDistance`。
- `applyPush` 里 `pushEndAt = now + ai.pushDuration`，但当时 `MonsterAiParams` 还没这个字段 → `NaN` → 永不生效。
- e2e 量击退距离必须在**停稳后**量（连续两拍位移 < 0.5px）：广播 100ms 一拍、击退 200ms，急着量只量到半路。
- `pickPointInArea(cx, cy, 0, 0)` = 恒定落中心点，e2e 用它把怪钉死，位置断言才可复现。

**测试**：新增 `server/test/e2e-monster-ai.cjs`（17 条，四段：别人打的伤害可见 / 击退 119.4px / C 晚进图坐标与 A
一致 / 尸体期 hits 0 条 + casts 0 次），套数 **38 → 39**（README + 站点三页同步）。
`make client-test` 有两套红：`test-skill-decouple`（期望值里写着 `push: {distance:120}`）与
`test-skill-snapshot`（断言 `after.push?.distance === 60`），按「击退已不在客户端」改写成**反向守卫**
（`push === undefined`）后 60/60 全绿。

**改到的文件**：服务端 `monster-ai.service.ts`（核心）/ `realtime.service.ts`（world 帧覆盖）/
`realtime.protocol.ts` / `world.service.ts`（注释）/ `combat-settlement.service.ts`（击退 + 注释）/
`runtime-config-cache.ts`（pushDistance）/ `config-sync.sql`（pushDuration 出厂值）/ `package.json`；
客户端 `MonsterAI.ts`（465 → 220 行）+ `MonsterManager` / `Game` / `SkillManager` / `types/{skill,monster}` /
`game-config.ts`（删 `monsterAI` 常量块）；工具 `audit-world-authority.cjs`（`BEHAVIOR_FIELDS` 反向守卫）、
`test-changed.cjs`。

**纪律收获**：显示效果（帧率/位置/尺寸）不写断言这条，在「击退」上反过来也成立 —— 击退**距离**是数值口径
（可断言、必须断言），击退**过程**是演出（不写）。e2e 只量落点，不量中间帧。
