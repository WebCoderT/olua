## P6 #962 客户端选服 → PR #989（`f6d8f35c`）→ epic #954 收尾关闭

P0~P7 八个子 issue 全部关闭，epic #954 结项。

### 用户拍板的两个交互口径（改变了 issue 正文的设想）

1. **选服弹窗不自动弹**：「弹窗是手动打开的，不点就显示默认的区」。
   登录后直接进选角页、停在上次那个区；弹窗唯一入口是选角页顶部「区服：X（点击切换）」。
2. **单区服不弹**（这条与最初设想一致）。

默认区优先级落成三段：本机 `ZoneStore`（还开放）→ 服务端 `current`（还开放）→ 最新开放区
（id 最大）。与 issue 写的「只有 1 个区有角色 → 不弹窗」不同 —— 不自动弹之后，「跳过」的语义
变成「入口不响应」。

### 做了什么

- 登录页**彻底与区无关**：删 `zoneSelector` 节点 / tap 循环 / `loadZones` / `zoneState`
  三态 / `login_zone_*` 四条文案；注册只发账号密码。
- `RoleSelector.bootstrap()` = `ensureZone()` → `loadRoles()`。**顺序不能反**：
  `GET /roles` 按当前浏览区过滤，区没对齐就拉会拉到上一个区的角色。
- 新增 `ui/components/dialogs/ZoneSelectDialog`：自建全屏模态（与 `ConfirmDialog` /
  公告提醒同形态），**每次打开重拉 `/zones/mine`**，维护 / 关闭的区照样占一行但置灰并给提示。
- 新增 `ui/core/ZoneStore`（`olua.zone`，一条 `{id, name}`）：偏好不是权威，脏数据当没记录。
  区名一起存是为了榜单 / 帮会标题（`zone_title_prefix`）。
- 换区收口 `onZonePicked`：退出管理模式 + 清删除按钮 + 清选中态 + 清旧列表 + 重拉。
- 服务端唯一改动：`ZoneDto` / `MyZoneDto` 补 `recommended`（P5 只落在库里、只在管理端发）。
- 跨区拒绝文案**没有**搬进 `texts.ts`：它在服务端（`PARTY_ZONE_MISMATCH` 50149），
  客户端只是展示。搬一份会变两份、迟早不一致。

### 踩坑

- `audit-ui-click-through` 报两处：新加的可点节点必须自己登记鼠标通道。
  文字节点用 `HAS_MOUSE ? bindMousePress : TOUCH_END` 双通道（照抄原 `Login.bindZonePicker`）；
  `createRoundedPanel` 内部虽已 `blockClickThrough`，但守点只认「节点变量赋值处 / 显式调用」，
  所以行节点上再显式写一次（幂等，`clickBlockedNodes` 是 Set）。
- `test-scene-stage.cjs` 崩在 `"position" in undefined`：`loginBlocks()` 里硬编码了
  `zoneSelector: layout.zoneSelector`，配置删掉后就是 undefined。删配置项要顺手搜测试里的同名引用。
- 该守卫还应加一条反向断言（「登录页不再拉活区列表」），否则功能回潮没人拦。
