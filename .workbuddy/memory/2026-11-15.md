## P6 #962 客户端选服 → PR #989（`f6d8f35c`）→ epic #954 收尾关闭

P0~P7 八个子 issue 全部关闭，epic #954 结项。

### 用户拍板的两个交互口径（改变了 issue 正文的设想）

1. **选服弹窗不自动弹**：「弹窗是手动打开的，不点就显示默认的区」。
   登录后直接进选角页、停在上次那个区；弹窗唯一入口是选角页顶部「区服：X（点击切换）」。
2. **单区服不弹**（这条与最初设想一致）。

默认区优先级落成三段：本机 `ZoneStore`（还开放）→ 服务端 `current`（还开放）→ 最新开放区
（id 最大）。与 issue 写的「只有 1 个区有角色 → 不弹窗」不同 —— 不自动弹之后，「跳过」的语义
变成「入口不响应」。

### 做了什么

- 登录页**彻底与区无关**：删 `zoneSelector` 节点 / tap 循环 / `loadZones` / `zoneState`
  三态 / `login_zone_*` 四条文案；注册只发账号密码。
- `RoleSelector.bootstrap()` = `ensureZone()` → `loadRoles()`。**顺序不能反**：
  `GET /roles` 按当前浏览区过滤，区没对齐就拉会拉到上一个区的角色。
- 新增 `ui/components/dialogs/ZoneSelectDialog`：自建全屏模态（与 `ConfirmDialog` /
  公告提醒同形态），**每次打开重拉 `/zones/mine`**，维护 / 关闭的区照样占一行但置灰并给提示。
- 新增 `ui/core/ZoneStore`（`olua.zone`，一条 `{id, name}`）：偏好不是权威，脏数据当没记录。
  区名一起存是为了榜单 / 帮会标题（`zone_title_prefix`）。
- 换区收口 `onZonePicked`：退出管理模式 + 清删除按钮 + 清选中态 + 清旧列表 + 重拉。
- 服务端唯一改动：`ZoneDto` / `MyZoneDto` 补 `recommended`（P5 只落在库里、只在管理端发）。
- 跨区拒绝文案**没有**搬进 `texts.ts`：它在服务端（`PARTY_ZONE_MISMATCH` 50149），
  客户端只是展示。搬一份会变两份、迟早不一致。

### 踩坑

## #769 同步系列第三刀：快照缓冲 + 服务器时间插值（PR #991，squash `14d7b285`）

第三刀与第二刀（#768 提频）是连着的：帧密了，但客户端那套「每帧走剩余一半」的指数逼近
把收益吃回去了 —— 数学上永远差最后几像素（停下蠕动一小段），延迟随帧率与丢帧漂
（抖一下目标点跳很远就快进，连丢两帧站着不动）。玩家体感是「忽快忽慢」。

### 做了什么

- 服务端两帧加**帧级** `t`（毫秒）：`players` / `monster-ai`。同一拍发出的所有帧共用一个值 ——
  players 用一拍一个 `tickAt`（各间房各取 `Date.now()` 会差出几毫秒），monster-ai 在广播出口取；
  全量帧、离开帧同样带齐；**AOI 按格裁剪后必须原样带上**（`t: data.t`）。
- 新增 `ui/core/SnapshotInterpolator`（纯数字、零 cc 依赖）：缓冲 4 条、同 t 覆盖、
  比最新旧丢弃、超容量挤最旧；采样夹住则线性插值、早于最旧钳到最旧、晚于最新沿最后一段
  速度外插且上限 100ms。
- 新增 `ui/utils/net/ServerClock`：welcome 粗校准（服务端时刻 − 本地收帧时刻）、
  pong 用「发出时刻 + RTT/2」细校准，**直接覆盖不做平滑**（抖动 < 渲染延迟一个零头，
  平滑只引入未知漂移）。
- 玩家（`OtherPlayerManager`）与怪物（`MonsterAI`）**共用同一个插值器**；怪物那边
  `serverX/Y/moving/stepAt` 全退役，缓冲挂 `WeakMap<Node, SnapshotInterpolator>`
  （`types/monster.ts` 不反向依赖 `ui/core`）。
- 朝向改按**这一帧的实际位移**算（位移 0 保持不动），走/站取后一条快照的 moving。
- 诊断层「插值剩余」→「插值落后」（渲染位置离最新已知位置的距离）；旧口径在新实现下无意义。
- 手感参数 `configs/network.realtime.interpolation`（120 / 4 / 100），人眼调、不进断言。

### 踩坑

- `test-client-net.cjs` 用**源码字符串**钉了 `this.pingSentAt = NetDiagnostics.enabled ? Date.now() : null;`。
  时钟校准要用发出时刻，只能改成「一律记」（RTT 入账仍由 `noteRtt` 在诊断关时空操作）——
  改实现就得同步改这条断言，不然是「改对了但红」。
- 加进 `ui/utils/net/` 的新模块必须**同时登记进 `client/tools/lib/net-sandbox.cjs` 的 FILES**，
  否则 tsconfig 里没有它 → 编译出缺 require 的 js，运行期才炸（不是编译期）。
- `make ci-static` 会先跑 `npm ci`：**worktree 里的 `node_modules` 软链会被替换成真安装**
  （`npm warn reify Removing non-directory`）。这其实是好事（真依赖更靠谱），但别指望软链省事。
- 先想清楚「一个 t 还是一串 t」：帧里同一拍的条目本就出自同一次 tick，给**帧级一份**就够；
  每条实体再带一份只是把同一个数重复 N 次。

`make e2e-all` **84 套**全绿。`e2e-protocol-slim` 38 → 45 条（`t` 两侧必填，`t?:` 会红）；
