## 2026-09-30 修复重进场景黑屏
- 根因：LayerManager 的 4 个静态图层容器（Map/Game/Effect/UILayer）只在模块加载时 new 一次并挂到旧场景 Canvas 下；地图切换=重进场景后旧场景销毁连带销毁静态节点，新场景 initLayer 把已销毁节点 addChild 回来 → 地图/角色/UI 全不可见（黑屏）。修复：initLayer 内每次重建 4 个图层容器。
- 连带修复全局监听残留（重进场景会叠加并引用已销毁节点）：RoleDisplay 键盘监听改命名方法 onKeyDown/onKeyUp + NODE_DESTROYED once 里 input.off；ScreenClick 新增 destroy()（input.off MOUSE_UP），Game.onDestroy 调用清理。
- 教训：静态类持有节点/相机跨场景时，进场景必须重建或重新注入；全局 input 监听必须随节点销毁移除。

## 2026-09-30 修复 ShortcutKey 键盘监听不生效
- 根因：Input.EventType.KEY_DOWN 是全局 input 单例事件，节点上 this.on(KEY_DOWN) 永远不会触发（节点只派发触摸类事件）。
- 修复：ShortcutKey 改为 input.on(KEY_DOWN, onKeyDown) 全局监听 + onKeyDown 内按 this.listenKey 过滤keyCode 后调用 onClick；updateIcon 换图标时先 offKeyDown 幂等移除再重挂；构造函数 NODE_DESTROYED once 中 offKeyDown，防重进场景残留。onClick 为空时只更新图标不注册监听。tsc 0 错误。
