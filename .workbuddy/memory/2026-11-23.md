## #1168 地图页左卡等高滚动未生效（PR #1174 → `5f090138`）

- 根因：**grid 行高 = 两列内容自然高度的最大值**。62 张地图的左列表自然高度 3000px+ 远超右列，行被左列撑开，#1151 的 `h-full` 等来的是「等高等于巨行」，滚动落到整页——「行高由右列决定」的假设只在右列更高时成立。
- 修法：lg 上左卡脱离文档流（外层 `lg:relative` 包裹 + 卡 `lg:absolute lg:inset-0`），绝对定位不参与行高计算，行高才真正由右列决定；窄屏单列 absolute 不生效回文档流。
- **并行会话踩坑实录**：修复在主工作区做完（未提交）后，被并行整理挪进 `~/worktrees/olua-1168`；主工作区切回 master 后 `git add` 报 no changes。教训：**改动一律在自家 worktree 里做并尽快提交**，主工作区任何时候都可能被并行会话 checkout 走；rebase 到最新 master（#1171 之后）无冲突，rebase 后必须复验 tsc + build。
