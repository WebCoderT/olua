## #1168 地图页左卡等高滚动未生效（PR #1174 → `5f090138`）

- 根因：**grid 行高 = 两列内容自然高度的最大值**。62 张地图的左列表自然高度 3000px+ 远超右列，行被左列撑开，#1151 的 `h-full` 等来的是「等高等于巨行」，滚动落到整页——「行高由右列决定」的假设只在右列更高时成立。

## #1184 进图/传送崩溃：兄弟重排队列残留已销毁节点（PR #1186 → `104ebe81`）

- 现象：预览里新号进图 / 点传送跳图 → 整页 Error「Cannot read properties of null (reading 'length')」，栈 `Node._updateSiblingIndex ← UITransform._sortSiblings ← Director.emit(AFTER_UPDATE)`；控制台另有引擎 5000（destroy twice）。
- 根因（引擎侧，cocos-engine#17890 同类）：`UITransform.onLoad/_parentChanged`（任何 addChild/换父/摘除）把**父节点**塞进静态 `priorityChangeNodeMap`，AFTER_UPDATE 统一重排；父节点若**同帧被销毁**，`_destruct` 已把 `_children` 置 null，重排读 `length` 抛；异常在 tick 内且队列在崩溃点之后才 clear → 之后每帧同一节点再崩。
- 兜底（`ui/utils/node/SiblingSortGuard.ts`，Loading/Game 模块顶层安装、幂等）：**只动 Node 的两个公开方法**——`_updateSiblingIndex` 跳已销毁节点 + 打节点名（`[engine-guard]`、上限 20）、`emit` 对已销毁节点直接返回。**不碰 `_sortSiblings`/`priorityChangeNodeMap`**：它们带 `@mangle`，release 构建可能改名，按名字取会静默失效。
- 顺带：传送弹窗「配置未就绪」提前 return 时 dialog 没销毁（孤儿泄漏）已修；allowlist 删掉 #1176 失效条目。
- 新单测 `test-engine-guard.cjs`：沙箱 cc 垫片复刻 `_sortSiblings` 链，跑**真实模块**（71 套）。
- **未完成**：根因那一侧（谁在同帧被销毁）靠 `[engine-guard]` 日志定位；用户复测后若出现该日志，按节点名回去修。
