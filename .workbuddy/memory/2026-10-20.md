## 远程分支整理（#157）

远端从 18 条收缩到 **2 条**：`master` + `portrait`。删的 16 条全是「一个功能一个 PR」的短线，`gh pr list --head <分支> --state all` 逐条核对都是 MERGED，没有可合并的内容。

**关键判据（squash 仓库必备）**：`git branch --merged master` 对 squash 合并**完全无效**（squash 后没有祖先关系）。能用的办法是

```bash
git merge-tree --write-tree <目标分支> <待判分支> | head -1   # 得到合并后的树
git rev-parse <目标分支>^{tree}                                # 对比
```

两者相等 = 该分支没有新内容（内容已被目标分支吸收）；不等 / 退出码非 0 = 有新增或冲突（冲突多半是「竖屏演进中间态」，最终形态已在 `portrait`）。

**安全性**：删掉的分支提交仍由 `refs/pull/<n>/head` 长期保留，随时 `git fetch origin pull/<n>/head` 取回。

**本地遗留**：还有 7 条 upstream 已 gone 的本地分支（chore/23、24、55、57，feat/5、59、61），PR 均 MERGED，内容已吸收 —— 用户只要求整理远程，本地暂留。
