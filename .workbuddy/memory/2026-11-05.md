## #702 Cocos 预览地址判定排查 + 页面参数覆盖（PR #703 / 6eb0b9c6，已合并关单）
- 用户报：Cocos 预览里 `isLocalHost(currentHost())` 恒 false。**Cocos 没有进程环境变量可注运行时**（预览页跑在浏览器里）——URL 查询参数就是预览环境的「环境变量」。
- `configs/network.ts` 加 `overrideFromQuery()`：`?oluaApi=<完整地址>` 最高优先级（HTTP + WebSocket 同时生效，`wsOriginOf` 本就支持绝对地址）；`?oluaApiEnv=prod`→同源 `/api`、`=local`→直连 3100；无 `URLSearchParams`（原生端）安全跳过。
- `resolveBaseUrl` 打 `console.info` 诊断日志：`[network] 按 host 判定 baseUrl：host=xxx → yyy`——预览时「为什么没直连 3100」一眼可见（这才是排查「恒 false」的正解：先看 host 到底是什么，常见原因是预览设置用了非本机 hostname / 真机扫码走公网 IP / hosts 配置）。
- 排查线索：Cocos 预览默认 `localhost:7456` 本应命中 true，恒 false 多半是「预览设置自定义了 IP/域名」或从部署站打开——先看日志里的 host 值。

## #706 详情背景动画比例修复（PR #707 / b64b8c72，已合并关单）
- 现象：详情弹窗背景动画有的拉高有的压扁。原因：`applyBackgroundEffect` 铺满拉伸（面板宽×高×scale），不看帧原始宽高比；素材各帧序列比例不一 + 弹窗高度随内容自适应。
- 修复：`createEquipmentDetailBackground` 先 `loadLoopFrames` 量第一帧 `originalSize` 得 ratio（帧缓存命中无额外成本）→ 回填 `ratio.value` 并按当前面板重设一次 → 再 `playLoopDir`（与边框流同口径）；`applyBackgroundEffect(node, effect, panel, ratio)`：**宽度 = 面板宽×scale，高度 = 宽度×帧比例**，ratio 未量到时铺满过渡。syncDialogSize 持 ratio 可变引用，弹窗尺寸再变用最新比例。
- 锚点默认 (0.5,0.5)，高度变化居中扩展；#700 显示效果语义不变（scale 乘宽度等比传导）。**要重新打包客户端才可见**。
- 经验：Cocos 里「铺满拉伸」类尺寸设置（CUSTOM sizeMode + setContentSize 面板尺寸）遇到比例不一的帧序列素材必变形——统一按第一帧比例量尺，异步量到后回填重设。
