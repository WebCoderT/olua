## #1102 输入框编辑期间不显示文字（PR #1103 已合）
- 用户实测：聊天输入框打字不实时显示、中文组词不可见，回车才出现——「像选中后偏移掉了」。
- 根因（引擎源码确证）：Web 端 EditBox 编辑时 `_hideLabels` 藏自绘 Label，改用绝对定位的 DOM input 覆盖层显示文字（`edit-box-impl.ts`）；本项目「UILayer 每帧跟主角搬 + 相机跟随」下该覆盖层落位不可靠。
- 修法（`UiHelper.createInputBox` 全项目输入框唯一来源，密码框除外）：编辑期间保持自绘 Label 常显（text-changed 本就实时同步 string）；DOM input 文字透明只留光标；组词期间用 DOM input 的 input 事件把草稿写进显示层 Label（只改 textLabel.string 不动 EditBox.string）。
- 坑：引擎 `beginEditing` 的 EDITING_DID_BEGAN 事件在 `_showDom`（藏 Label）**之前**发出，延一拍 setTimeout(0) 再点亮才不被盖回去。
- 门禁：client-check 0 错 + ci-static 绿。
