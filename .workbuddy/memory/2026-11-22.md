## #1150 换图收尾：#1084 主线链 + 刷怪区一起重铺

背景：开发库期间丢了 `quests` 232 环与 6 段任务 NPC（8005~8246 / npcs 0101~0106），用户拍板
「连刷怪区一起重铺」，于是用 `server/scripts/oneoff-seed-quest-chain.ts` 重跑并重排 `map_spawn_areas`。

### 布局算法换了：同心环 → 格点
- 旧脚本按**旧图 0（8192×8192，6700 万 px²）**把 220 个 220×220 的区全铺一张图（只占 16%）；
  新图 0（DT2101）只有 2304×1856 = 427 万 px²，220 区是整图的 2.5 倍 —— 物理放不下。
- 先试「按段分图 + 同心环」，图 0 摆到第 11 个就满：**轴对齐方块的非重叠判据是
  `max(|dx|,|dy|) ≥ 边长`**，环上 45° 方向两个分量都只有弦长/√2，按弧长算的容量高估。
  → 改成「区边长 + 60」的**格点**（两轴间距恒定，天然满足判据），格位由外向内取，
  boss 按等间隔占最外圈，格位 ±8 抖动。脚本自带「格位不够就抛错」，不会静默丢怪。
- 最终：图 0 33 区（边长 170）、图 2 38（170）、图 4 37（190）、图 6 38（190）、
  图 8 38（190）、图 10 36（190）；Σmax = 4022；6 位任务使者落图 0 村中心。
- **图 0 仍是 1-10 猎场**：试过把 band1 挪走（村内不刷怪），用户当场否掉 ——
  「出门即死不要管，这种情况需要玩家自己团结起来去解决」。不要为「出生点安全」改玩法数据。

### 这轮踩的坑（e2e）
- 图 0 第一个实例现在是 **10 级 boss**（区按外圈先铺 boss）：
  - `e2e-combat` 拿 `monsters[0]` 当靶子 → 1 级角色打上去 `damage:0 / suppressed`（等级压制），
    改成「编号最小的怪」；顺手把写死的 `monsterKey:"1"` 换成服务端发的那只（否则实例与 key
    不符 → `unknown_target` 假红）；追击断言给 2px 整数化容差。
  - drop 三套同样改成「编号最小的活怪」（boss 掉落表可能是空的，打死了也不掉）。
- `e2e-push` 击退观测：**AI 帧只在「有变化」时才推**，怪被推完就静止 → `framesDelta = 0`，
  表现成「等待超时」而不是「没推动」。改法：①pos 帧保活（400ms 一次，否则玩家被判离线）；
  ②`leashRange` 放大到 10 万（否则推开 512 就掉头回家，看到的是反方向）；③不用 `waitFor`
  探这条谓词（超时后还有 `worldJoin` 权威快照兜底，用 waitFor 会把兜底前的等待记成红）。
- `e2e-map` 怪物名断言写死「赤焰斗鸡」 → 改成从快照 `monsters` 表按 key 查。
- 摸底手法：`node /tmp/survey.cjs`（不分片、不 fail-fast、并发 3）一次列全红名单；
  **并发 3 跑会让 party 这类时序套件假红**，红名单要单跑复核再改。
## #1151 地图管理页左列等高 + 卡内滚动（PR #1152 → `1d729a7b`）

- 用户要求：地图列表固定高度、多余滚动、与右侧一致。改法只在 `MapsPage.tsx` 一处 className：
  左卡 `flex h-full flex-col overflow-hidden` 吃满 grid 行高（行高由右列决定），
  卡体经 `[&>div]:min-h-0 [&>div]:flex-1 [&>div]:overflow-y-auto` 变滚动区。
- 关键点：`Card` 公共件没开 body className 口子 → 用任意子选择器命中正文 div（header 是 `<header>` 不受影响）；
  **`min-h-0` 是 flex 子项触发 overflow 的前提**（与 Layout 那节同一个根因）；
  grid 子项默认 stretch + `h-full`，窄屏单列时行高 auto、`h-full` 退化为无约束。
- 验证：admin tsc 0 错 + build 过 + `make audit` 19 项全绿；显示效果留给用户人眼（本机无 playwright）。
- 场景注意：动笔时主仓库在 `feat/1150-new-maps` 且有别的会话在改（admin models.ts 等）——
  本刀全部在 worktree 进行，没碰主仓库工作区。
