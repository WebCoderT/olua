## #1269 管理端下拉框 UI 异常（PR #1271 已合，master = cfd94eff）
- 现象：所有 `<select>` 的箭头是 macOS 原生「⇕」双箭头控件（用户截图：掉落流水筛选条四个下拉框全可见），粗重、与 legend 主题不搭。根因：`Select` 组件把深色 `CONTROL_CLASS` 直接套在原生 select 上，没做 `appearance-none`。
- 修法只改 `admin/src/components/ui.tsx` 一处，全站 113 处生效：`appearance-none` + `pr-8` 留白 + 自绘向下 chevron SVG（`text-ink-4`、`pointer-events-none`）。**`className` 语义不变但落到定宽外层**（select 恒 w-full 撑满）—— 顺带消灭「Select 自带 w-full 与调用方 w-24 同属性打架」这个规范挂过号的老坑（MapMonitor 两处受益）。页面代码零改动。
- 验证：audit-admin-ui 七条全过（53 页 + 24 组件）+ `make admin-build` 过；headless Chrome 复现确认「⇕ → chevron」。
- 坑：① 定位时先怀疑「箭头不可见」，裁图放大才发现真身是 macOS ⇕ —— **sips 裁切 cropOffset 参数是 (offsetY, offsetX)**，裁偏了两次；② 本轮 GitHub API 抽风：`gh pr create` GraphQL 连续 502/500、REST `POST /pulls` 也 500，最小 payload 隔离确认是服务端故障；**502/500 的请求可能已服务端建单成功** —— 重试后 422 "already exists"，查回来是个标题 "probe" 空 body 的 PR #1271，用 `PATCH /pulls/:n` 补全标题描述后 `PUT /pulls/:n/merge` 合并。以后遇到 GitHub 5xx：先查 `GET /pulls?head=...` 再盲目重试，防重复建单。

## #1268 刷新后图标「无图」要切页才恢复（PR #1270 已合，master = 1442a5ed）
- 根因：gameData / mapCatalog 是模块级缓存（Layout 挂载异步拉一次，页面同步查表）；页面首渲时快照没到，查表空串 → GameIcon「无图」；落地只写模块变量、无 React 信号，已挂载页面停在首渲态，切页重挂载才恢复。
