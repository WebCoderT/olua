## 收尾：浏览器实机验证（本轮）与四处真回归
- **本地构建 + Playwright 实机跑通**（用户本轮授权「自己本地验证」）。构建命令（`env -i` 必须，否则注入的 `ELECTRON_RUN_AS_NODE` 让 CLI 认不出 `--project`）：
  `env -i HOME=$HOME TMPDIR=/tmp PATH=<node bin>:/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin CocosCreator --no-sandbox --project client --build "configPath=/tmp/olua-build.json"`
  - `TMPDIR` 不能瞎写（写 `/var/folders` → polyfill 子进程 `EACCES mkdir /var/folders/tmp-xxx`）；`PATH` 要含 node（polyfill 用子进程）；`--build "platform=web-desktop;debug=true"` 在 3.8 是空跑（13 秒、产物 0 文件），**只能用 configPath**。
  - `open -a CocosCreator --args --project` 不转发参数（停在 Dashboard），编辑器预览路线走不通。
- 驱动要点：`window.cc` 可用；HUD 的 `ui_layer` 世界坐标是 (4057,-3688)（被平移过），点节点必须经 `Canvas/Camera.worldToScreen` 换算，不能拿 worldPosition 当屏幕坐标；游戏场景里 `locator.click` 会报「html 拦截指针」，改用 `p.mouse.move/down/up`；客户端**没有 Escape 关闭逻辑**（一直如此），关弹窗要点 `*_close_button`。
- **本轮修掉的 4 个真回归**（都是矢量化遗留，实机才暴露）：
  1. `applyShortcutKeyStyle` 里 `node.getComponent(UITransform).setContentSize` → `ShortcutKeySlot extends Node` 是裸节点、不再挂 Sprite（旧靠 `@requireComponent` 顺带建 UITransform），空引用抛错把 **整个 BottomBar 构建打断 → 游戏内 HUD 全空**。改 `?? addComponent(UITransform)`。
  2. `createRoundOrb` 的 Mask：`mask.type = GRAPHICS_STENCIL` 会先触发引擎 `_createGraphics()` 自建空白 Graphics，我们后加的 Graphics 不参与模板 → **血球/魔法球渲染成纯色方块**。必须「先 addComponent(Graphics) 再设 type」。
  3. 球内数值被液面盖住：RoleHpOrb / RoleMpOrb 里文字先挂、球后挂 → 调换顺序。
  4. `smallMapLayout.nameBar.position` / `bottomRow.positionBar.position` 有配置但代码没 `setPosition` → 地图名跑进地图正中、坐标条压在地图中间。
- **小地图按稿重排**：rail 回 5 颗**单列纯图标**（world/achievement/mail/config/sound），排行榜/线路挪到地图正下方两颗文字胶囊（`small_map_foot_*`，线路胶囊文字兼显「N 线」）；rail 图标与底栏导航图标都走新写的 `ui/helpers/VectorIcon.ts`（SVG path→Graphics，支持 M/L/H/V/C/S/Q/T/A/Z，数据逐字抄 `design/olua-ui` 内联 SVG，存 `configs/layout/icons.ts`）。
