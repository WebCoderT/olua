## #1280 客户端配置快照按版本门控（PR #1281 已合，master = 5070c0d1）
- 用户报「前后缀文字颜色不按管理端配置显示」。渲染与保存链路（prefixColors → applyEquipmentQualityLabels → getEquipmentNameParts → Label.color）都通；根因在 **ConfigLoader.loadSnapshotOnce 进程级只拉一次快照、无版本门控**——管理端改任何快照配置，客户端重进图/重登都拿旧值，重启进程才生效。
- 修法：每次进图先拉轻量 `GET /game-config/version`（Public，几十字节），`snapshotVersion === version` 直接放行，不一致才拉全量快照落库并记版本；并发去重语义保留。改动只有 ConfigLoader.ts + 守点。
- 守点补在 test-equip-align-apply.cjs 第七节：version 请求 + 版本比对 + 全量请求只在 loadSnapshotOnce 内（反证法验证红）。**踩坑提醒：反证后 `git checkout <file>` 会把未提交的修复一起还原**——先提交再反证。
- 门禁：ci-static 绿；e2e-all 首轮挂 map-path（ECONNREFUSED 服务端掉线，本刀纯客户端不可能背锅），单跑 27/27 绿 + 第二轮全量 96 套绿 = 分片抖动既有样本。
- 推论：以后「管理端改了 X 客户端看不到」先查快照版本链（config_version 是否 bump / 客户端是否重进图），不再是「必须重启进程」。
