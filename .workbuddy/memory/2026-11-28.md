- 修法：configs/items.ts 加 `isBagFull(bag, rows?, cols?)`（配置尺寸内全格有物才算满，脏数据防御）；AutoBagService.runOnce 回收段前置改 `getAutoRecycle && isBagFull(role.bag)`——未满不扫不发请求，满了才一批收掉（recycleBySelection 一次请求收全部勾中装备）；onBagFullRejected（服务端 bag_full 拒绝路径）本来就是满时才动+无匹配零请求，不动。文案同步（auto_recycle_hint「背包放满时…一次性回收」）。
- 单测：test-auto-bag.cjs 加 isBagFull 行为断言（全满/空格/行缺失/自定义尺寸/越界行）+ runOnce 源码断言锁「开关 && isBagFull」前置（#1289 旧写法回潮红，已反证）。门禁全绿（82/82、97/97）。**需重打客户端包**。
