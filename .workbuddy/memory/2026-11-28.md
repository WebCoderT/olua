- 根因：`rule` 声明 `@property({ type: Node })`，prefab 里却指向 `__id__ 5`（Rule 节点的 cc.UITransform），应指 `__id__ 4`（节点本身）。UITransform 也是 Component 但不是 Node，无 setPosition → 实例化不崩、一调方法就崩。**#1398 修的是三向接线（children/comps/组件 node），自定义属性引用是第四类，漏了**
- 修复：prefab 一行（rule→4）；守点补 `propRefProblems`——从组件源码解析 `@property({ type: Node|Label })` 字段声明（单一真相），断言 prefab 引用目标 `__type__` 匹配，DialogFrame/DialogFoot 双查；反证 3 条（rule→UITransform 必红且文案命中 / 非属性字段不误报 / 字段名写错拿 null）
- 教训：手写 prefab 的引用校验是四向——三向接线 + **自定义 Node/Label 类型 @property 引用的目标类型**；后者实例化期不炸、运行期才炸，更隐蔽
