## HUD 三块 UI 对齐同一套设计语言（用户指出「地图框 / 聊天框 / 正下方操作框明显不一致、图标颜色完全不同」）

**病根**：聊天框用的是 `T.surface.scrim`（纯黑 62%）+ `T.surface[0]` 描边 —— 冷黑、没有可见边框；
旁边小地图与底栏是暖褐玻璃 + 古铜金发丝线，于是「暖褐面板之间夹一块黑洞」。
图标另有一个口径错误：小地图 rail 画成 `gold[3]`，而稿 `.map-rail button{color:var(--text-2)}` 是**骨白**（金色只给底栏 `.nbtn .ic`）。

**改法（全部对照 `design/olua-ui/screens/04-hud.html` 的 CSS 值）**
- `chatDialogLayout.box`：`surface.glass` + `line[3]` + `radius.r3` + `border.width`（稿 `.chat .panel` / `.panel--rivet`）。
- 页签：`idleFill=sunken / idleText=text[3] / idleBorder=line[2]`，选中 `gold[3] + text.onGold`（稿 `.chat-tabs`）。
- 消息行：`fill/border` 都改 `overlay.transparent`（稿 `.msg` 是纯文字行），**新增 `row.text`** 当正文色 ——
  早前正文色借的是 `row.border`（改描边会顺手改掉字色），现在解耦；两色透明时组件跳过画底板。
- 输入条：`surface.input` + `line[2]` + `radius.r2`（稿 `.chat-in .input`）。
- rail 图标 `gold[3]`→`text[2]`，底栏导航统一 `line[2]`（早前按解锁态切 `gold[2]`，一排两种线）。
- 快捷格快捷键字母 `Color.WHITE`→`text[4]`、冷却字 `text[2]`（稿 `.sslot .k`）。
- 小地图底图加 `UIOpacity`（`smallMapLayout.mapView.imageOpacity=128`，稿 `.terrain{opacity:.5}`）+ 视口 `line[1]` 发丝线。
- **`drawVectorIcon` 线宽下限提到 1.5px**：16~18px 图标按 1.7/24 折算只有 1.1px，抗锯齿后每像素只染四成颜色，
  实机是「暗棕糊块」而不是金线（这条是「图标颜色完全不同」的主因，色值本身没错）。
- 新增 `GameUiHelper.createHudBackdrop` + `bottomBarLayout.backdrop`：整屏宽、竖向 alpha 渐变的底部暗角
  （稿 `.bottom::before`），底栏不再「几块板子漂在亮底上」。
  坑：Graphics 没有渐变填充 → 切条模拟；**node 坐标 y 向上，i=0 是最下面那条**，第一版把方向写反了（上黑下亮 + 硬边）。
  条宽必须整屏等宽，按高度收窄会出「台阶」。

**验证**：`client-check` 0 错 · `client-test` 70/0 · `make audit` 19/19 · CLI 构建 + Playwright 实机，console 0 报错。
实测像素：聊天框内部 (39,32,23)（改前 (60,57,54) 冷灰）、导航/技能格/rail 全部 (32~43,27~36,19~28) 同一族；
设计稿实测面板边 = `gold3 @ .48`（= `line[3]`）、内件边 = `gold3 @ .26`（= `line[2]`），与改后一致。

**仍不是 UI 问题**：底栏右侧那块亮青色是**世界里的水池 tile**（`map_layer/map_0/ground`），
不是压住 UI 的色块（导航格/技能格像素实测被底板盖住，是暗的）；它亮是因为地图美术本身亮，HUD 压暗它属于地图表现话题。

## 小地图按 04-hud 稿重写 + 引擎 1px 描边坑（本轮）
- **引擎坑（重要，全端 UI 都受影响）**：Cocos 3.8.7 web 构建里 **Graphics 的 1px 描边整条不渲染**（2px 正常，最小实验证过：fill+1px stroke 与纯 1px stroke 都不可见）。
  - 稿里的「1px 古铜发丝线」用 `stroke` 画在实机上等于没画 —— 这才是「弹窗/rail/视口框都没有边框」的真因，不是配色问题。
  - 修法（`drawGlassPlate` / `createDialogPanel`）：先按描边色填满整块，再内缩 `bw` 填主体色 → 恒 1px 清晰边线；填充为透明时改画四条 1px 实心窄条。
- `dialogFrame.panel.fillTop` 原成 `surface[2]`（与主色同档 → 没有渐变、面板死平），稿 `.panel` 顶是 `surface-3`，已改。
- 小地图 = 稿 `.map` 段逐值落地：面板 304×250（右边距 20 / 顶边距 14 → 中心 (788, 401)）、head 40（gold-5 图名 + `· N线` 副文字 + 12px 下拉箭头）、`.map-view` 280×170（r2、line-1 边、径向底 surface[1]→[3]→[4]、22px 金网格、底图 opacity .5 + 压暗薄纱、inset 26px 暗角）、rail **2 列 ×4 行 7 颗**（world/channel/ranking/achievement/mail+红点/config/sound，按钮 rgba(22,15,9,.92)≈surface[2]）、foot 只剩右下 `X 128 Y 96`。
  - 排行榜/线路**在 rail 里**，不是地图下方胶囊（上一轮看漏稿改错了，已回退）。
  - 点位：玩家 gold-5 白点 r4 + 10px 外环；怪物 ember-3 r2.5。
  - 暗角用「四边各 13 条 2px 实心条」近似（描边圆角矩形会叠出同心底纹；条宽 6px 会看出分层）。
- 布局键变动：`nameBar`/`bottomRow`/`mapFrameSize`/`textEntryLabels` 删除，新增 `head`/`contentPosition`/`mapView.backdrop|grid|scrim|vignette`/`positionBar`。
