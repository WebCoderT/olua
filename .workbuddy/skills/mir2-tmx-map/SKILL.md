# 传奇瓦片素材 → TMX 地图生成

把 Mir2 风格的地面瓦片素材库（.tga 或已转的 .jpg）程序化拼成 Cocos Creator 可用的 `.tmx` 地图。

## 核心工作流（4 阶段）

### 1. 素材转换（TGA→JPG）
- 用 `scripts/tga2jpg.py <src_root> <out_root>`（Pillow，8 进程）
- 参数固定：`quality=95, subsampling=0`（像素画边缘不糊）
- 保持原分组目录结构镜像

### 2. 素材分析选型
- 用 `scripts/analyze_groups.py` 做全库分类：主色调分类（草地/泥土/石头/水面等）+ **无缝度评分**（接缝差异/内部差异，`<1.35` 为可用，`<1.0` 极佳）
- 无缝度高的做基底，带杂质的做装饰
- 肉眼复核：生成带序号的瓦片图（PIL ImageDraw 标注文件名）再 Read 查看

### 3. 地图生成
- 用 `scripts/build_village_v2.py`（v2 = 参考格式版；改头部 BUNDLES/布局参数即可换地图）
- 关键结构：BUNDLES 素材束 → GID 分配 → 4 层绘制(内部) → 合并 ground/wall → TMX 输出 → 预览渲染

### 4. 校验
- 解析 TMX：firstgid 连续性（next = firstgid + tilecount）、层行列数、GID 越界、每个 tsx 引用的图片存在

## ⭐ TMX 输出格式（用户提供的 参考地图格式/ 是权威标准，必须遵守）

1. **每个素材一个 .tsx + 一张图**，与 .tmx 同目录（这就是"地图文件夹自包含"）：
   - tsx 可为单瓦片（如 384x384 大地砖、704x832 大树 PNG）或多瓦片网格（di_zhuan_2=2块、di_zhuan_3=4块）
   - 同材质变体打包成一个网格图 + 一个 tsx
2. **外部 tsx 引用**：`<tileset firstgid="N" source="xxx.tsx"/>`，**firstgid 按引用顺序累加**：next_firstgid = firstgid + 该 tsx 的 tilecount
3. **图层只用两层，英文小写**：`ground`（地形：草地/路/广场/水/农田）+ `wall`（立体物件：建筑/岩石/树/装饰）
4. **大瓦片对齐规则**：大于格子的瓦片锚定在格子**左下角**向上延伸（Tiled 正交地图规则）；384x384 大地砖每 3 格放一次可铺满 3x3 区域
5. 地形用 JPG，带透明的物件用 PNG
6. 头部：`version="1.10" tiledversion="1.12.2" orientation="orthogonal" renderorder="right-down"`，CSV 编码。**⚠️ CSV 每行末尾必须带逗号（最后一行除外）**——实测 Tiled 1.12.2 无逗号直接报"图层'ground'数据已损坏"
7. tsx/图片命名用**拼音分类编号**：cao_di_N 草地、tu_lu_N 土路、shi_ban_N 石板、shui_mian_N 水面、yan_shi_N 岩石、wu_ding_N 屋顶、nong_tian_N 农田、hua_cong_N 花丛、an_shi_N 岸石、mu_zhuang_N 木桩、sha_di_N 沙地
8. **不要**生成 .meta 文件——Cocos Creator 导入时自动生成

## 必踩坑（已验证）

| 坑 | 解法 |
|---|---|
| 多层合并成 ground/wall 时优先级写反，水井被广场盖住 | 平面装饰(井/岸石/花) > 道路 > 草地基底；wall = 建筑/岩石 > 平面装饰 |
| 草地混多个组的瓦片会显脏（亮度不齐像马赛克） | 基底用单组为主（84%）+ 同色系组少量点缀；深色组只放边缘 |
| 素材库亮蓝水（073/00000）太刺眼 | 用青绿水（074）融入草地色系 |
| 路肩噪点太碎 | 柔化概率 ≤25%，且只取正交相邻格 |
| TGA alpha 全为 255（无实际透明） | 转 JPG 直接丢 alpha，无损失 |
| 素材库只有不透明地面瓦片，无建筑/树精灵 | 房屋用屋顶纹理块表现（俯视风格）；要侧视建筑需补充带 alpha 的对象素材 |
| ~~内嵌 tileset~~（v1 做法，已废弃） | 用户参考工程实际用外部 tsx + .meta（Cocos 自动生成），照参考格式走 |
| **CSV 行尾无逗号 → Tiled 报"数据已损坏"（行=N,列=3 即 </data> 处）** | 每行末尾加逗号、最后一行不加（Tiled 原生格式）。用 Tiled CLI `--export-map` 实测验证 |

## Mir2 素材库结构经验

- 分组目录 = 数字 ID，组内瓦片是同材质的变体（互为无缝）
- 特殊组：`073/00000/` 是嵌套子目录（纯水面）；组内偶有 `00027-1.jpg` 这类双轴编号
- 分组规模集中在 9 张 / 16 张
