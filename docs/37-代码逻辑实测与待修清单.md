## 零、一句话结论

**当前服务端是「能跑通单机演示」的完整度，不是「能开服」的完整度。** 三个最硬的洞：

1. **一次 `cast` 不做冷却/耗蓝/距离/频率/死亡校验** —— 改包即可 1 秒清空全服 BOSS（B1）；
2. **商城允许标价 0，回收价独立** —— 运营一次误配即无限印钞，不需要改包（B2）；
3. **日常任务领奖后删行、无日切** —— 接→杀→交→再接，奖励无限刷（B3）。

这三条之外，还有 40+ 条是「功能名存实亡」或「数据会慢慢漂」。逐条在第二节。

## 一、P0：改包或一次误配就能打穿的四条

### B1 · 战斗判定链缺 6 道闸

实测 `combat-settlement.service.ts:166-208`（`settleNew`）**实际只有 9 步**：
技能存在 → 怪物配置存在 → 实例存在 → `monsterKey` 一致 → **同区（只比 zoneId）** → 目标存活 → 角色在线 → 技能已学 → 有伤害系数 → 扣血。

**没有的**：

| 缺的闸 | 证据 | 后果 |
|---|---|---|
| 冷却（`skill.cooldown`） | 全文件无 `cooldown`；只有怪物 `tryCast:777` 读 | 1 秒技能可每秒放 1000 次 |
| 耗蓝（`mp_cost`） | 全仓 `mpCost` **无任何消费方** | 蓝条是装饰；技能 1004 蓝耗 10 万也不影响 |
| 距离 / 射程（`skill.distance`） | `settleNew` 未读该字段；不取攻击者坐标 | 隔整张图打怪 |
| 跨图（`mapId`） | 只比 `zoneId`（`:185-188`） | 站主城打任意图怪物（`instanceId` 可枚举） |
| 施法者存活 | `:192` 只检查 `online`，**不看 hp** | 尸体持续输出，死亡惩罚形同虚设 |
| 出手频率 | `realtime.service.ts:554` 无节流（聊天都有限流：`chat.service.ts:244`） | 单连接万次/秒 |
| 等级要求（`level_req`） | 只在「学技能」时校验（且学技能接口不存在，见 G1） | — |

**修法方向**：判定链按 `存活 → 距离 → 冷却 → 耗蓝 → 结算 → 记冷却` 顺序补齐，**冷却记录必须落库或进程内带 TTL**（重启丢冷却可接受，丢一次不算漏洞）。

### B2 · 免费商品 + 独立回收价 = 无限绑定元宝

- `mall-pricing.service.ts:217`：`price: dto.price ?? 0` —— **允许 0**。
- `roles.service.ts:419-423`：`0 < 0` 为假 → 购买通过。
- `roles.service.ts:475-497`：回收按 `sellPriceOf`（装备=变体价、药/材料=表价）**与商城价无关**。

结果：上架一件 `price=0` 但 `sell_price>0` 的商品 → 无限买 → 无限卖。**不需要改包。**

**修法方向**：商城价下限 1；或加「回收价 ≤ 商城价 × 0.5」的全局约束（`sellPriceOf` 侧夹取）。

### B3 · 日常任务可无限重刷

`quest.service.ts:128-130`：`if (kind === "daily") remove(progressRow)` —— 领完删行。`accept:66-97` 不检查「今天是否已完成」，全模块**无日切**。

结果：接 → 杀 → 交 → 再接，一条日常一天刷上千次。成就「累计交付 N」同被刷。
