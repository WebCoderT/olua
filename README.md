# olua

一个使用 Cocos Creator 制作的 2D 角色成长与装备玩法原型。项目目前包含登录、角色选择和游戏场景，并持续完善角色外观、属性、背包与界面交互。

## 当前内容

- 场景：登录、角色选择、游戏，以及加载场景。
- 角色成长：泡点活动按时间增加经验，角色经验与等级可动态更新，并展示升级特效。
- 角色表现：支持角色动画、朝向和动作切换，可在场景中更新角色位置。
- 装备与属性：支持穿戴装备、更新装备外观、查看背包，并计算和实时更新战斗力等角色属性。
- 地图与界面：包含地图定位和复活逻辑、角色信息弹窗、底部导航及血量显示。

## 技术与运行

- 引擎：Cocos Creator 3.8.7
- 脚本：TypeScript
- 打开方式：使用 Cocos Creator Hub 打开本仓库目录，在编辑器中打开 `assets/scenes` 下的场景并运行预览。

仓库的 `package.json` 当前记录了 Creator 版本，没有定义 npm 启动或构建脚本；项目运行依赖 Cocos Creator 编辑器。
