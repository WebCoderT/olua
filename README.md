# olua

一个基于 Cocos Creator 3.8.7 的 2D 角色成长与装备玩法原型，聚焦登录、角色创建、角色成长、装备系统、地图探索与战斗玩法（打怪 / 掉落 / 技能 / 自动战斗）的交互演示。

## 项目简介

这个项目目前包含以下几部分：

- 登录场景、角色选择与创建场景
- 游戏场景主循环与地图切换（Loading 过渡场景，带进度显示）
- Tiled 地图渲染与对象组驱动：NPC 点位、复活点出生、矩形刷怪区、碰撞区
- 角色属性、等级与成长系统（HP / MP / 攻防区间 / 战斗力）
- 装备系统：穿脱、属性汇总、内外观（8 方向外观位置 / 缩放 / 旋转）、装备详情弹窗
- 战斗系统：技能触发统一入口、冷却（按动作速度折算）、魔法消耗、伤害飘字、击退
- 怪物系统：区域刷怪、AI 行为（待机游走 / 主动追击 / 普攻）、信息面板、选中光圈
- 掉落系统：按权重概率掉落、地面散落、走上去自动拾取 / 点击拾取
- 自动战斗：快速攻击与自动挂机开关，基于 A* 寻路绕障碍走位
- 状态（Buff）系统：技能附加状态、身上循环特效、头像下方图标条
- 资源预加载：进图前预载地图、NPC / 怪物帧动画与角色穿戴外观

## 当前成果

- 使用 Cocos Creator 的场景、节点、组件和 UI 系统搭建了完整的主流程。
- 支持角色创建、在线角色存储、角色选择和进入游戏，进图统一从地图复活点出生。
- 支持泡点活动、经验获取、等级提升和升级特效。
- 支持键盘（WASD/SHIFT）与鼠标（左键走/右键跑、按住拖动实时改向、左键点怪攻击、右键点怪选中）双操控，八方向动作与朝向。
- 支持装备系统：装备槽与背包均按物品 id 引用存储（改配置重启即生效）、穿戴校验（等级/性别/职业）、属性汇总与战斗力计算。
- 装备/物品配置齐全：32 件衣服、21 把武器、戒指/项链/鞋子/头盔/腰带等，均带图标、内外观与介绍文案。
- 支持技能系统：12 个技能配置（动作、冷却、魔法消耗、特效、击退、状态），快捷键 6 格绑定与冷却倒计时显示。
- 支持怪物 AI：开图按区域生成、待机游走、进入检测范围追击、普攻结算、碰撞互相阻挡。
- 支持掉落与背包：怪物死亡按掉落表产出，自动拾取入包，背包按 id 引用渲染。
- 支持状态 Buff：护体神盾等技能给自身附加状态，特效跟随 + 图标倒计时。
- 支持自动战斗：挂机开关 + 快速攻击，A* 寻路绕开障碍与怪物走位，卡住自动换目标。
- 支持 HUD 全家桶：角色信息栏（头像/货币/战斗力/状态图标）、血球魔法球、经验条、快捷键栏、小地图（坐标 + 附近怪物红点）、怪物信息面板。
- 支持自定义鼠标指针：指向怪物变攻击指针、指向物品按大类变色。

## 目录结构

- assets/configs：数值与静态配置（按域一文件：role/monster/skill/equipments/items/drop/map/status/hudLayout 等）
- assets/types：纯类型声明（common/role/animation/good/skill/map/monster/drop/status）
- assets/entities：运行时实体（Role）
- assets/skills：技能行为实现（技能实现只依赖 SkillContext，不反查全局）
- assets/ui：界面脚本
  - ui/core：静态管理器（GameHelper/LayerManager/MonsterManager/MonsterAI/DropManager/SkillManager/StatusManager/EffectManager/AutoBattle/PreloadManager/StorageManager/RoleUIManager/SceneManager 等）
  - ui/components：按职责分组（hud/panel/dialogs/role/input/map）
  - ui/helpers：UI 生成（UiHelper 基础封装 / GameUiHelper 零件库 / AnimationHelper 帧动画）
  - ui/utils：纯函数工具，按功能域分目录（battle/drop/map/physics/resource/input/cursor/node）
- assets/resources：资源目录（地图 tmx、帧动画、图集、图标、UI 素材）
- assets/scenes：登录、角色选择、加载和游戏场景
- public：截图和展示素材

## 技术栈

- Cocos Creator 3.8.7
- TypeScript

## 运行方式

1. 安装并打开 Cocos Creator 3.8.7。
2. 通过 Creator 的 “Open” / “Open Project” 打开当前仓库目录。
3. 在编辑器中打开 assets/scenes 下的场景文件。
4. 使用预览或播放按钮运行项目。

注意：这个仓库本身不提供 npm start 或 build 脚本，项目依赖 Cocos Creator 编辑器来启动和预览。

## 预览与常见问题

如果在 Cocos Creator 预览时出现类似下面的报错：

- TypeError: Cannot read properties of null (reading 'width')
- Preview Error: [Window] ... reading 'width'

通常表示编辑器预览阶段的 Camera / Canvas / Window 绑定尚未完成，或者场景中相机/画布初始化时访问了空的窗口对象。这个问题通常出现在 Cocos 编辑器的预览启动过程，而不是纯 TypeScript 逻辑本身。

建议检查：

- Canvas 节点是否存在且已正确绑定 Camera
- Camera 组件是否被挂载在 Canvas 的子节点
- 场景启动时是否有脚本在 Camera 尚未初始化完成前读取视口尺寸
- 是否在编辑器 Preview 与实际运行环境中切换过分辨率策略

如果遇到该错误，优先确认场景中 Camera 与 Canvas 的组件关系和初始化顺序，再重新运行预览。
